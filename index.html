    Why it is not duplicated here

    One optimizer engine, two runtimes

    The current optimizer is a tested Rust crate. GitHub Pages cannot execute the native binary, so the next bridge packages that same crate as WebAssembly. The browser UI will use its existing request/response contract without maintaining a second scoring implementation.

    Rust crate → WASM adapter → Browser

    rLogs Web Lab · Static, versioned, and privacy-reviewed by default.
