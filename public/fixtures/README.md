# Public website fixtures

- `bpsr-character-profile.v1.json` is a synthetic contract example.
- `marierose-asteria-capture.v1.json` is a user-authorized, sanitized public
  profile projection from a real Global/Asteria world-load capture.

The real fixture contains the public character identity and allowlisted profile
state needed to test equipment, module, skill, talent, profession, progression,
appearance, and collection views. It does not contain packet bytes, network
addresses, account/login fields, credentials, tokens, cookies, private chat, or
capture evidence.

The source capture remains private and is never a website artifact.
